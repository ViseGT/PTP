# 鋼構吊裝 PTP（作業前危害辨識）

給 iPad／iPhone 用的鋼構吊掛 PTP（Pre-Task Plan）網頁 App。由領班在吊裝前帶工班把「吊裝劇本」走一遍，確認人員身心狀態、標記並排除現場危害，所有條件通過後才放行。

> 機具本身（一機三證、鋼索斷股、卸克規格、吊索夾角）請併同 **CraneCheck 高風險吊掛檢點表** 執行，本 App 不重複卡控。

## 功能

| 步驟 | 內容 |
|---|---|
| 1. 基本資訊 | PTP-01 共 21 項（基本資訊、人員通訊、場地與混同作業、PPE 防墜、緊急應變）。風速 ≥ 10 m/s 自動判定強制停工 |
| 2. 人員身心 | 睡眠、酒氣、身體不適、嗜睡藥物、情緒；精神 1–5 分；血壓、酒測（選填）。異常者須替換，檢核通過才能親自簽名 |
| 3. 劇本排練 | 六階段（卸料堆置 → 掛設試吊 → 起吊迴轉 → 高空對孔 → 卸鉤撤離 → 收工復原），逐條確認控制對策、指派負責人、情境提問。iPad 可用「專注模式」給全班看 |
| 4. 危害標記 | 上傳作業區照片或平面圖，直接點位置標記危害；填風險等級、對策層級、負責人、排除前後照片 |
| 5. 放行 | 8 項放行條件全過才能由領班簽名放行；條件變更時記錄動態修訂（PTP-03B）並自動暫停 |
| 匯出 | PTP 報告（單一 HTML，含照片與簽名，可列印成 PDF）、危害清單 CSV、摘要文字 |

另可匯入「作業許可單」CSV，自動帶入承攬商、區域、吊車操作手、指揮手與吊掛物。

## 上傳到 GitHub Pages

1. 在 GitHub 建立新 repository（例如 `steel-ptp`），把本資料夾內**所有檔案**上傳到根目錄（`.gitignore` 也要上傳）。
2. 進入 repo 的 **Settings → Pages**。
3. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1–2 分鐘後網址會出現在同一頁，例如 `https://你的帳號.github.io/steel-ptp/`。

> 免費帳號的 GitHub Pages 網站是**公開**的，知道網址的人都能開啟。但 PTP 填寫的資料只存在每台裝置自己的瀏覽器裡，不會上傳到 GitHub。

## 安裝到 iPad／iPhone 主畫面

1. 用 **Safari** 開啟上面的網址。
2. 點「分享」→「加入主畫面」。
3. 之後從主畫面圖示開啟，會以全螢幕 App 方式執行；第一次開啟後，沒有網路也能使用。

## 資料存放（重要）

- 資料存在**該台裝置的瀏覽器**（IndexedDB），不同裝置之間**不會同步**。
- 在 Safari 刪除網站資料或清除瀏覽紀錄會一併刪掉 PTP。
- iPhone／iPad 若長時間未開啟，系統可能清除網頁資料；請定期在首頁按 **「匯出備份」** 存成 JSON，需要時用 **「匯入備份」** 還原，也可用來把 PTP 搬到另一台裝置。
- 若要多台裝置即時同步，需要另外接後端伺服器（本版本未包含）。

## 示範資料

首頁按 **「載入示範資料」** 會帶入 4 份虛構 PTP：

| PTP | 狀態 | 適合示範 |
|---|---|---|
| F22P4 FAB L30 主樑吊裝 | 已放行 | 全部完成的樣子、危害排除前後照片 |
| F18P9 LB1 次樑／斜撐 | 排練中 | 人員替換、第 4 階段 X、高風險危害擋住放行 |
| F20P1 CUP 屋頂鋼構 | 暫停・重新評估 | 動態修訂紀錄、風速超標 |
| F25P2 FAB L40 鋼柱 | 準備中 | 剛從許可單建立、疲勞注意 |

`demo/示範_作業許可單.csv` 可用來示範許可單匯入（10 筆吊掛 + 1 筆高架，高架會被自動濾掉）。所有人名、公司、電話皆為虛構。

## 作業許可單 CSV 格式

UTF-8（可含 BOM），第一列為欄位名稱，至少需要「作業類別」「施工內容」：

```
廠別,作業類別,主承商,次承商,單號,施工開始日期,施工結束日期,施工區域,狀態,風險判定,施工內容,作業細項,施工檢查,施工狀態,工安,工安電話,監工,監工電話,施工人數
```

- 只保留「作業類別」含「吊掛」且施工狀態不是「施工取消」的資料。
- 「施工內容」中若有 `車號:`、`吊掛物:`、`預計吊掛物最大重量：`、`吊車操作手:`、`指揮吊掛手:` 等欄位，會自動帶入 PTP。
- 許可單只存在匯入的裝置上；**真實許可單請勿放進 repo**（`.gitignore` 已排除 `*.csv`）。

## 更新版本

修改 `index.html` 後，請把 `sw.js` 第 2 行的 `VERSION` 改成新的值（例如 `steel-ptp-v2`），已安裝的裝置下次開啟時才會更新。

## 判定紅線（可依廠區規定調整）

- 風速 ≥ 10 m/s：強制停工（`index.html` 搜尋 `>=10`）
- 血壓 ≥ 160/100、酒測 > 0、精神 5 分、任一檢核項 ✕：判定異常
- 精神 4 分：疲勞注意（可作業，須加強監看）
